# Code Review — 提交前 10 分钟扫出安全漏洞和 bug

**解决什么问题**：代码里藏着 SQL 注入、硬编码密钥、N+1 查询，人工 review 一遍要 30–60 分钟还容易漏。这个技能把审查清单塞进 Claude，一句「审查这段代码」，10 分钟输出分级问题报告 + 每个问题的具体修法。

**装了就干嘛**：把代码 / PR 贴给 Claude，触发 `code review`，自动按「安全 → 正确性 → 性能 → 可维护性 → 测试」五维审查，输出 CRITICAL / HIGH / MEDIUM / LOW 分级问题 + 带文件:行号的修复建议。

**为什么值**：
- 覆盖 9 项安全 + 8 项质量 + 6 项性能检查清单，比人肉 review 全、不漏
- 每次省 30–60 分钟；一天 review 3 次就是省 2 小时
- 输出带具体修复代码，不是泛泛的「建议改进」

**定价**：免费版 = 基础检查清单；完整版 **$29** = 全流程 + 案例库 + 输出模板 + 持续更新 + 私域支持。见 `PRICING.md`。

**安装**：见 `INSTALL.md`（30 秒）。

**案例**：见 `examples/`，看真实输出长什么样。
